# FMU 기반 스마트 주차장 디지털 트윈

FMI 표준 시뮬레이션(FMU)과 디지털 트윈을 연동한 스마트 주차장 플랫폼이다.
디지털 트윈 데이터 저장·관리 도구 과제에서 개발했으며, 컴파일된 `.fmu` 바이너리와 데이터는 포함하지 않는다.

<br>

## 구성

- **Co-simulation 오케스트레이션** (`main_orchestrator.py`)
  - 마스터 오케스트레이터(초기화 → 실행 → 종료), 시간/스텝 스케줄러, FMU 어댑터, I/O 브로커, 변수 매핑, 상태 연계(스냅샷·롤백)
- **주차장 도메인 FMU** (`fmu/`) — 20여 개 FMU 모델을 5개 카테고리로 구성
  - 실시간 모니터링 : 시설/존/공간 점유, 차량 위치, 장치 상태
  - 예약·거래 : 입출차, 결제, 무결제 감지
  - 예측/AI : 점유율·수익·혼잡 시간대
  - 통계·리포트 : 일별 지표·체류시간·수익 추세
  - 운영 최적화 : 동적 요금, 예방정비 스케줄링
- **필터 규칙** (`fmu_filter_rules.py`) · **설정** (`fmu_config.py`)
- **테스트** (`test_*_fmu.py`) — FMU별 단위 검증

<br>

## 메모

- 각 FMU의 **소스(`fmu/*.py`)만 포함**하고, 컴파일된 `.fmu` 바이너리는 제외했다.
- `json/`의 예시는 실제 시설 정보를 지운 더미 데이터다.
- 디지털 트윈 연동 대상(MQTT/WebSocket, Eclipse Ditto)의 접속 정보는 포함하지 않는다.

<br>

## 기술 스택

Python · FMPy(FMI 표준) · Eclipse Ditto · MQTT/WebSocket · FastAPI/REST · Docker
